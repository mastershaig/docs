title: "Environments & Secrets"
description: "Per-suite environments with a base URL, variables and encrypted secrets"
---

An **environment** lets you run the same suite against Production, Staging, or any
other target without editing the tests. Each suite can have several environments,
each with its own base URL, variables, and secrets.

## What an environment holds

| Field | Purpose |
| --- | --- |
| **Name** | For example `Production` or `Staging`. |
| **Base URL** | When set, the test's start-URL origin is swapped to this base URL, so the same tests run against a different host. |
| **Variables** | Plain `{{name}}` values available to your steps, e.g. `coupon_code=SAVE10`. |
| **Secrets** | Encrypted `{{name}}` values, e.g. `login_password`, that are never shown or logged in plaintext. |
| **Locale / timezone** | Optional [locale settings](/language-locale-testing) applied to the browser. |

Mark one environment as the **default**. Per-test runs and scheduled runs use the
suite's default environment; when you run a whole suite you can pick which
environment to use.

## Using variables and secrets in steps

Reference environment values with the double-brace syntax:

```text
Type {{coupon_code}} into the discount field and apply it
Type {{login_password}} into the password field
```

See [Variables](/variables) for how `{{name}}` differs from runtime `{name}` values.

## How secrets are protected

<CardGroup cols={2}>
  <Card title="Encrypted at rest" icon="lock">
    Secret values are encrypted at rest. The API only ever returns secret **key
    names**, never the values.
  </Card>
  <Card title="Masked in evidence" icon="eye-slash">
    Secret values are redacted from persisted step text, AI analysis, replay
    records, and the public share page.
  </Card>
</CardGroup>

<Warning>
  A typed secret can still appear in low-level run artifacts such as a form POST body
  captured in the network panel, or in the prompt sent to the AI provider. Use test
  accounts and test data, never real customer credentials or live payment details.
</Warning>
